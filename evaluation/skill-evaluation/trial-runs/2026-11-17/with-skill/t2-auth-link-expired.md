## 当前情况：授权链接过期

这是已定义的失败场景，处理原则是：**重新生成新的授权链接或二维码，绝不复用旧值**。旧链接作废即可，不影响你之前填写的 App ID。

## 先确认一件事

飞书授权页只存在于**完整发行包（邀请制内测）**中。请看一眼你本地页面的形态：

- 如果你的页面曾是**飞书授权页**（要求填 App ID / App Secret）→ 你持有完整发行包，按下面步骤重新生成即可。
- 如果你装的是**公开仓 mind-kit**，页面标着「Vault-only」→ 公开包**本身不含飞书同步连接器**，「当前公开发行包不含云文档、知识库同步连接器」是边界设计、不是故障，无法通过重新授权解决。需要飞书同步请到 <https://aip.cab/services> 申请完整发行包。

## 如果你是完整发行包，重新生成授权的步骤

由**你**来操作，我待命确认结果：

1. **保持安装器进程运行**（不要关闭终端窗口）。
2. 在终端中**重新运行安装器**，生成一次性授权链接/二维码：
   - Windows（PowerShell）：
     ```powershell
     Set-Location .\mind-kit
     .\install-second-brain.ps1
     ```
   - macOS/Linux：
     ```bash
     cd mind-kit
     ./install-second-brain
     ```
3. 打开安装器新输出的 `http://127.0.0.1:<port>/wizard?...` 本地页面（以这次新输出的地址为准，**不用旧地址**）。
4. 在本地页面上重新完成授权并点击同步。

## 安全提醒

- App ID / App Secret 只填写在本机 `127.0.0.1` 页面，不要出现在聊天、命令行历史、截图或仓库中。
- 不要把旧 token / 旧授权链接拿回来恢复使用，一次性授权只认新生成的值。
