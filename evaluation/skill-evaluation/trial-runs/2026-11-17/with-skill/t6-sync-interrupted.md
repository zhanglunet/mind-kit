**不要找回旧 token。** 直接说结论：授权链接和 token 都是一次性的，中断或过期后不复用旧值——这是设计如此，复用旧 token 不仅大概率直接失败，也违反本工具的安全规范（我不读取、不回显任何 token，你也别去翻日志里的 token 或把带 code 的链接贴出来）。

## 正确做法

1. **保持安装器进程运行**，别关掉那个终端窗口。
2. 看本地 `127.0.0.1` 页面现在的提示，分两种情况：
   - 页面有「重新生成授权链接 / 二维码」入口 → 直接生成**新的**，在浏览器打开新链接重新授权；
   - 页面已无法操作或卡死 → 重新运行一次安装器（就是你当初安装时的那条命令），生成新的一次性授权。
3. 重新授权并点击同步后，同步会按增量状态继续，不需要手动“续传”。完成后检查输出目录里是否有非空 Markdown，以及增量状态是否正常。
4. 如果错误信息是 `missing_scope`：去飞书开发者后台开通缺失的权限并**发布新版本**（不发版权限不生效），再从本地页重新授权。
