如果软件不支持一键授权，可能需要手动配置：

- 开通云文档相关权限（一般是文档只读权限）
- 把生成的 App ID / App Secret 填到 mind-kit 的集成配置里
- 如果你在企业组织内，应用发布可能还需要管理员审核
