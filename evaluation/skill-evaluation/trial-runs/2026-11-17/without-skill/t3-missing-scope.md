`missing_scope` 是 OAuth 授权的常见报错，意思是当前授权令牌缺少同步所需的权限范围。可以按下面的思路排查：

## 1. 最常见的修复：重新授权（重新连接账号）

- 在同步工具中**断开/解绑当前账号**，然后重新走一遍授权流程
- 原因：如果应用后来新增了需要的权限，旧的 token 不会自动获得，必须重新授权才能生效

## 2. 看清报错详情，确认缺的是哪个 scope

- 报错信息里通常会列出缺失的 scope 名称（如 `calendar.readonly`、`drive.file` 等）
- 记下具体名称，方便对照排查

## 3. 如果你是自建应用/开发者，检查应用侧配置

不同平台的入口不一样：

| 平台 | 检查位置 |
|------|---------|
| Google | Cloud Console → OAuth 同意屏幕 → 确认对应 scope 已添加 |
| Notion | 开发者门户 → Integration → Capabilities，开启对应权限 |
| 飞书/Lark | 开放平台 → 应用 → 权限管理 → 添加权限 → **发布新版本**（容易漏这步） |
| GitHub | 检查 OAuth App 请求的授权范围是否包含仓库读写等 |

## 4. 企业账号需管理员批准

- 公司/组织账号（Google Workspace、企业微信、飞书企业版等）可能需要管理员在管理后台审批该应用的权限申请

## 5. 以上都不行时

- 清除应用的缓存和旧凭证，重新登录
- 查看该工具的文档，确认同步功能要求的完整权限清单
