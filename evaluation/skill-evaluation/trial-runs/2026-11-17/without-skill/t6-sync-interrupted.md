不建议去找回旧 token，直接在还开着的安装器里重试更稳妥。

**原因：**

1. **旧 token 大概率已失效**——飞书的 access token（user_access_token / tenant_access_token）一般 2 小时左右就过期，同步中断后旧的基本已经作废，找回来也用不了。
2. **重新授权很快**——安装器还开着的话，直接点“重试”或重新连接，会触发新的授权流程，自动拿到新 token。
3. **进度一般不会丢**——多数同步工具支持增量同步或断点续传，重新连接后会接着上次的位置继续，或者自动去重，不用从头同步。

**什么情况才需要手动处理 token？**

只有开发者调用飞书开放平台 API 时才涉及手动管理 token，而且正确做法也是用 app_secret 重新获取新 token，而不是找回旧的。普通安装软件用不到这一步。
