服务：飞书同步与第二大脑部署

一句话:把你自己的飞书云文档 / 知识库拿回自己手里——增量备份为 Markdown, 跑在你自己的机器上,接你自己的账号。自托管:凭证在你的系统钥匙串, 数据在你的目录,我们全程零接触。

这是什么

飞书个人数据备份和同步能力已经进入公开的 mind-kit，不再需要私有仓邀请、访问令牌或 单独发行包。Workbuddy 可以直接从公开仓启动安装器。

能力 说明
云文档备份 本人授权可见的飞书云文档 → Markdown，支持增量同步
知识库备份 飞书知识库(wiki)按空间/路径落盘为 Markdown
云盘与消息 按本人实际申请并获批的权限同步文件、群聊和单聊
多账号 一台机器管多个飞书账号,数据目录自动隔离
失败可见 与 mind-kit 的失败通知层配套:定时任务挂了会通知你,不会静默烂掉

先看门槛(如实说)

这不是代管账号的云服务；现在可以由 Workbuddy 启动一键安装向导，但飞书应用创建、 权限申请和扫码确认仍必须由你本人完成：

  • 一台 macOS、Linux 或 Windows 电脑；Windows 使用原生 PowerShell，不需要 WSL
  • 需要在你的飞书租户创建企业自建应用并扫码授权(手册给逐步说明; 只涉你本人的文档,不需要读他人数据的审批)
  • token 有 7 天刷新窗口,需要一条保活定时任务;断供 7 天要重新扫码
  • 能力以你租户的权限策略为准——“作者能跑”不保证”你能跑”,装前看清单
  • 依赖第三方 CLI(lark-cli),发行版锁定版本并如实声明依赖边界

作为对价:你的凭证和数据从不经过我们,退出 = 删本地数据 + 删自建应用,完。

怎么开始

不需要申请。打开 Workbuddy 专用安装向导，依次完成：

  • 把公开仓链接和页面中的第一段提示词交给 Workbuddy
  • 在浏览器中由本人创建飞书自建应用、申请权限并确认授权
  • 回到 Workbuddy 执行同步、编译与验收提示词

如果需要企业内网部署、权限方案评审或迁移支持，可以在 mind-kit Issues 提交需求；这是可选服务， 不影响公开安装器和基础同步能力的使用。

边界与承诺

  • 不做:微信个人号消息同步(无官方 API,协议手段有封号与法律风险, 永久不提供);托管代跑(替你保管 token 与数据——那是另一种产品形态, 当前明确不做)
  • 开源免费：mind-kit、安装器和本地同步模块按仓库许可证提供
  • 可选服务：企业权限梳理、部署与运维支持另行约定，不代管你的凭证和数据
