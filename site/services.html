服务：飞书同步与第二大脑部署

一句话:把你自己的飞书云文档 / 知识库拿回自己手里——增量备份为 Markdown, 跑在你自己的机器上,接你自己的账号。自托管:凭证在你的系统钥匙串, 数据在你的目录,我们全程零接触。

这是什么

两条线,边界如实说:

  • 公开仓 mind-kit(开源免费):第二大脑工具集本体, 含 Vault-only 一键安装器——初始化本地知识库目录骨架与本地工具,支持 macOS / Linux / Windows(原生 PowerShell,不需要 WSL)。 公开包不含飞书同步连接器,不能执行飞书内容同步。
  • 完整发行包(邀请制内测,免费):飞书个人数据备份套件,交付私有发行仓只读访问 与《订阅者部署手册》,含下表能力。
能力(完整发行包) 说明
云文档备份 「我拥有的」飞书云文档 → Markdown,增量,重跑只补新内容
知识库备份 飞书知识库(wiki)按空间/路径落盘为 Markdown
多账号 一台机器管多个飞书账号,数据目录自动隔离
失败可见 与 mind-kit 的失败通知层配套:定时任务挂了会通知你,不会静默烂掉
云盘与消息 进阶模块,后置:云盘待陌生租户实测,消息需你租户管理员审批 scope

先看门槛(如实说)

这不是代管账号的云服务;安装器能自动化的只有本机环境,飞书应用创建、 权限申请和扫码确认必须由你本人完成:

  • 一台 macOS、Linux 或 Windows 电脑;Windows 使用原生 PowerShell,不需要 WSL
  • 需要在你的飞书租户创建企业自建应用并扫码授权(手册给逐步说明; 只涉你本人的文档,不需要读他人数据的审批)
  • token 有 7 天刷新窗口,需要一条保活定时任务;断供 7 天要重新扫码
  • 能力以你租户的权限策略为准——“作者能跑”不保证”你能跑”,装前看清单
  • 依赖第三方 CLI(lark-cli),发行包锁定版本并如实声明依赖边界

作为对价:你的凭证和数据从不经过我们,退出 = 删本地数据 + 删自建应用,完。

怎么开始

  • 只想要本地第二大脑:直接用公开仓,见 Workbuddy 专用安装向导—— Vault-only 安装器把目录骨架和本地工具一步建好,不涉及任何飞书凭证。
  • 要飞书备份(完整发行包):邀请制内测,名额以单人能认真支持的数量为限。 在 mind-kit Issues 开一个 issue, 标题带「邀请申请」,说明使用场景与环境(macOS / Linux / Windows); 通过后你会收到私有发行仓的只读访问与《订阅者部署手册》。

如果需要企业内网部署、权限方案评审或迁移支持,同样在 Issues 提交需求; 这是可选服务,不代管你的凭证和数据。

边界与承诺

  • 不做:微信个人号消息同步(无官方 API,协议手段有封号与法律风险, 永久不提供);托管代跑(替你保管 token 与数据——那是另一种产品形态, 当前明确不做)
  • 开源免费:mind-kit 与 Vault-only 安装器按仓库许可证提供
  • 内测免费:完整发行包邀请制内测阶段不收费;未来若收费会提前明示, 已装功能不受影响
