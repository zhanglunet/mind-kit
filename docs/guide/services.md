# 服务:飞书个人备份套件(邀请制内测)

> **一句话**:把你自己的飞书云文档 / 知识库拿回自己手里——增量备份为 Markdown,
> 跑在**你自己的机器**上,接**你自己的账号**。自托管:凭证在你的系统钥匙串,
> 数据在你的目录,**我们全程零接触**。

## 这是什么

本站的第二大脑工具集(mind-kit,开源免费)之外,还有一套**私人集成发行版**:
飞书个人数据备份套件。当前**邀请制内测,免费**。

| 能力 | 说明 |
|---|---|
| 云文档备份 | 「我拥有的」飞书云文档 → Markdown,增量,重跑只补新内容 |
| 知识库备份 | 飞书知识库(wiki)按空间/路径落盘为 Markdown |
| 多账号 | 一台机器管多个飞书账号,数据目录自动隔离 |
| 失败可见 | 与 mind-kit 的失败通知层配套:定时任务挂了会通知你,不会静默烂掉 |

## 先看门槛(如实说)

这不是代管账号的云服务；现在可以由 Workbuddy 启动一键安装向导，但飞书应用创建、
权限申请和扫码确认仍必须由你本人完成：

- 会用终端、能装 CLI、能配 cron
- 需要在你的飞书租户创建**企业自建应用**并扫码授权(手册给逐步说明;
  只涉你本人的文档,不需要读他人数据的审批)
- token 有 7 天刷新窗口,需要一条保活定时任务;断供 7 天要重新扫码
- 能力以**你租户的权限策略**为准——"作者能跑"不保证"你能跑",装前看清单
- 依赖第三方 CLI(lark-cli),发行版锁定版本并如实声明依赖边界

作为对价:你的凭证和数据**从不经过我们**,退出 = 删本地数据 + 删自建应用,完。

## 怎么申请

邀请制内测,名额以单人能认真支持的数量为限:

- 在 [mind-kit 仓库](https://github.com/zhanglunet/mind-kit)开一个 issue,
  标题带「邀请申请」,说明你的使用场景与环境(macOS/Linux)
- 通过后你会收到发行包(私有仓访问或 tarball)与《订阅者部署手册》

拿到完整仓库后，按 [Workbuddy 专用安装向导](workbuddy.md) 操作：页面提供两段可
直接复制的提示词，并在中间明确标出必须由本人完成的飞书授权步骤。

## 边界与承诺

- **不做**:微信个人号消息同步(无官方 API,协议手段有封号与法律风险,
  永久不提供);托管代跑(替你保管 token 与数据——那是另一种产品形态,
  当前明确不做)
- **免费**:内测阶段不收费;未来若收费会提前明示,且已装功能不受影响
- 工具集本体(mind-kit)始终开源免费,发行版只是私人集成部分
