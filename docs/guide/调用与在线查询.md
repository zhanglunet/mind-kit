# 调用与在线查询指南(北极星:调用率)

> 2026-07-16 落地。本文是"**怎么用第二大脑回答真问题**"的操作手册:三条调用通道、首页在线查询的架构与管理、记账规则、已知限制与排障。配套代码:`scripts/brain-server.py`、`scripts/build-portal.py`、`scripts/com.mind.brain-server.plist`。

## 一、调用率是什么、怎么被计数

- **定义**:每周拿库回答**真实问题**的次数(决策查询 + 写作取料)。判据:答案改变了接下来做的事。
- **节奏目标**:每周 ≥2 次(1 次决策查询 + 1 次写作取料);周一周报综述时回顾。
- **计数机制**:每次有效调用在 `_wiki/log.md` 追加一条 `## [日期] query ｜ <问题>`;日报/周报脚本与首页记分牌都从这里数。**在线查询命中时由 brain-server 自动记账;无命中不记(不掺水)。**

## 二、三条调用通道(按问题选)

| 通道 | 入口 | 适合 | 产物去向 |
|---|---|---|---|
| **引擎在线查询** | 首页「🚀 在线查询」/ `sage-wiki query "…"` | 事实型、单点("库里关于 X 说了什么") | 自动存 `_wiki/under_review/`(gitignore);值得的手工提升为 outputs |
| **Claude Query 工作流** | 首页「🤖 复制给 Claude」→ 贴进 Claudian/Claude Code | 跨源综合、决策分析、写作取料(**引擎索引不含 material/ 素材卡,这类必须走 Claude**);可联网补缺并标注「库内/联网」 | 直接写 `_wiki/outputs/` 加 `dimension:` + 记 log |
| **/boss** | Claude Code 里 `/boss <议题>` | 重型决策(5 评委合议) | reports/<slug>/ |

闭环:`问题 → 查询 → under_review → 值得 → outputs + dimension → 五维看板自动汇总 → log 记账 → 报表/记分牌计数`。

## 三、首页英雄区(browse/index.html「🎯 问一下第二大脑」)

- **提问框** + **五维模板芯片**(与 `_wiki/outputs/五维决策看板.md` 同一套模板,点芯片自动选中 `<议题>` 待替换)。
- **🚀 在线查询**:POST 给本地服务,页面内出答案(`[[内链]]` 自动链到 wiki 页);服务没起时按钮置灰并提示启动命令。
- **🤖 复制给 Claude / ⚙️ 复制引擎命令**:一键装弹,贴走即用。
- **记分牌**:构建时从 log.md 算「本周 N/2 · 累计 N」;≥2 变绿。**每日 cron 重建门户时自动刷新**。
- **最近决策产出**:outputs 里带 `dimension:` 的页,按日期倒序直链。

## 四、brain-server 本地服务(在线查询的引擎)

```
浏览器 ──POST /api/query {"q":…}──▶ brain-server.py @ 127.0.0.1:8788(纯标准库)
                                      ① 子进程 sage-wiki query(产物照常落 under_review/)
                                      ② 无命中 → 停用词切分 + 滚动二元组 → 自动重查一次
                                      ③ 命中才追加 log.md 记账
                                      └ 顺带静态托管 /browse /site /docs(同源零 CORS)
```

- **API**:`GET /api/ping` → `{ok, engine, browse_stale}`(`browse_stale=true` 表示浏览站落后于知识库,该重跑 `build-wiki-site.py`;`null`=尚未构建);`POST /api/query` → `{ok, hit, fallback, logged, answer, saved}`,请求体可带 `"eval": true` 声明评测流量(不写调用记账);`POST /api/search` → `{ok, results:[{path,title,score,channels,snippet}]}` **秒级本地检索**(searchlib:bigram 索引 + 中英同义扩展 + 三通道 RRF,不走 LLM、不记账,索引随知识库变化自动刷新)。
- **入口**:`http://127.0.0.1:8788/`(推荐收藏,根路径即门户);旧 file:// 打开也能查(API 已放 CORS)。
- **安全**:只绑 127.0.0.1;静态目录白名单 `{browse, site, docs}` + 路径穿越防护;子进程不走 shell。
- **端口**:8788(8787 被系统 `reattachd` 占用)。改端口:`--port`,同时改 `build-portal.py` 里的 `API` 常量。

### 常驻管理(LaunchAgent)

```bash
# 安装(已装):
cp scripts/com.mind.brain-server.plist ~/Library/LaunchAgents/ && launchctl load ~/Library/LaunchAgents/com.mind.brain-server.plist
# 日志 / 重启 / 卸载:
tail -f ~/.mind-brain-server.log
launchctl kickstart -k gui/$UID/com.mind.brain-server
launchctl unload ~/Library/LaunchAgents/com.mind.brain-server.plist && rm ~/Library/LaunchAgents/com.mind.brain-server.plist
```

plist 用 `zsh -c 'source ~/.zshrc; exec python3 …'` 启动——**引擎查询需要 ~/.zshrc 里的 GLM_API_KEY**,直接跑裸 python3 会缺 key。

## 五、已知限制与排障

| 症状 | 原因 | 处置 |
|---|---|---|
| 长自然句"库内无命中" | **引擎 BM25 无中文分词**,整句当一个词撞索引(2026-07-16 实测) | shim 已自动兜底(关键词化重查,实测同题 105s 出带内链答案);仍无命中→换 2–6 字关键词,或走 Claude 通道。**真解 = P2-1 装 Ollama embedding 开向量检索**,届时自然语句直接命中 |
| 「在线查询」按钮灰 | 本地服务没起 | `launchctl list \| grep com.mind.brain-server`;没有就按上文安装;临时 `python3 scripts/brain-server.py` |
| 查询报"引擎退出码"且 detail 含 key/auth | LaunchAgent 环境缺 API key | 确认 ~/.zshrc 里有 GLM_API_KEY;`launchctl kickstart -k` 重启 |
| 查询很慢(1–2 分钟) | GLM 综合正常耗时 | 页面有计秒;别关页 |
| 记分牌数字没动 | 门户是构建时快照 | 等每日 10:00 cron,或手动 `python3 scripts/build-portal.py` |

## 六、演进方向

1. **P2-1 向量检索**(根治长句无命中):`brew install ollama` + embedding 配置后,shim 的分词兜底可自然退休。
2. sage-wiki 自带 Web UI 需 `go build -tags webui`(当前 build 未含);若未来启用,shim 的静态托管职责可移交,但**记账钩子**仍需保留。
3. 想把"写作取料"也做成按钮:给 Claude 的复制模板已含工作流约定,可再加一颗「✍️ 取料」芯片(六类素材专用模板)。
