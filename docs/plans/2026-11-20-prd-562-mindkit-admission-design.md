## 2. 准入检查五层

| 层 | 口径 | 结论 |
|---|---|---|
| L1 质量门 | 口径/公式复算不过不进 | 完整=过；缺项=不过（进整改） |
| L2 安全扫描 | 取数越界/敏感表扫描 | 命中=不过；无命中=过 |
| L3 重叠检测 | 与已有分析 skill 语义重叠不过不进 | 疑似=待人工复核（不自动判死） |
| L4 合成评测集 | 合成分析题，表格上跑，答案钉值 | 有评测集+钉值=过；无=待补测 |
| L5 实测评估 | 真实表格跑一遍，结果与人工结论对照 | 有对照数据=过/不过；无=待补测 |

- 结论封闭：过 / 不过 / 疑似 / 待补测
- 任一层「不过」→ 一票否决；「待补测/待复核」→ 拦下但不判死（证据不足不是失效）。

## 3. 准入结论封闭词表

| 结论 | 含义 | 动作 |
|---|---|---|
| 可进收件箱 | 五层全过 | 进收件箱等人拍板（机器不代行） |
| 不进（整改） | L1 质量门缺项 / L2 安全命中 | 进整改清单 |
| 待复核 | L3 疑似重叠 | 人工确认合并/拆分/保留 |
| 待补测 | L4 无评测集 / L5 无对照数据 | 补齐后复检 |
